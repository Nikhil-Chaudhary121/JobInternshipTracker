#Job/InternshipTracker

> a simple web app to track internship / job status interview date 

## Overview 
we apply on so many internships and job and tracking them is a pain to this web app will help you track down ur internship and job proccess 

## Key feature
-[] a clean dash board where we can create our applied job/internship details 
-[] we can update the status of our job/internship
-[] user can login/ register

## Tech Stack 
* **Fronted:** React.js / Tailwind CSS 
* **Backend:** Node.js / Express.js 
* **DateBase:** MongoDB
